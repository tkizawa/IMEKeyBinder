# IMEKeyBinder

Windows環境で英語配列（USキーボード）を使用する際に、Macライクに日本語入力（IME）を素早く快適に切り替えるための常駐ツールです。

---

## ✨ 主な機能

- **右 Alt 単体押し・離し**: **IME ON** (日本語入力)
- **左 Alt 単体押し・離し**: **IME OFF** (直接入力/英語)
- **ショートカットキーとの完全な両立**:
  - `Alt + Tab`, `Alt + F4`, `Alt + Space`, `Alt + Shift`, `Alt + 任意のキー` などの既存ショートカットキーは**一切邪魔されず通常通り動作**します（IMEの意図しない切り替えも発生しません）。
- **メニューバー誤フォーカス防止**:
  - Windows標準の「Altキー単体押しでウィンドウ上部のメニューバーにフォーカスが吸われる」問題を自動的に抑制します。
- **高い互換性（ハイブリッド切り替え方式）**:
  - メモ帳などのクラシック Win32 アプリケーションから、Chrome / Edge / VS Code / Windows Terminal / UWP アプリ等のモダンアプリまで確実に切り替えが反映されます。
- **タスクトレイ常駐**:
  - 起動すると画面を邪魔せず画面右下のタスクトレイ（通知領域）に常駐します。
  - アイコンの左クリックで設定・テスト画面を表示、右クリックで手軽に各種設定や終了が可能です。
- **スタートアップ自動起動対応**:
  - Windowsログオン時に自動起動する設定がアプリ内からワンクリックで設定可能。
- **多重起動防止**:
  - 二重起動によるキーフックの重複を防ぎます。

## 🚀 使い方

### 1. 起動方法
```powershell
# デバッグ実行
dotnet run

# またはビルド済みEXEを直接実行
.\bin\Release\net10.0-windows\IMEKeyBinder.exe
```

起動すると、タスクトレイに「IME」アイコンが表示され、すぐにキー監視が有効になります。

### 2. 操作方法
- **右 Alt キーをポンと押して離す** → 日本語入力が ON になります。
- **左 Alt キーをポンと押して離す** → 日本語入力が OFF になります。
- **Alt キーを押しながら他のキーを押す** → 通常のキーバインド（例: `Alt + Tab` など）がそのまま実行されます。

### 3. 設定・テスト画面の表示
- タスクトレイのアイコンを**左クリック**または**ダブルクリック**すると、設定・テスト画面が開きます。
- 画面上の「テスト入力エリア」で実際に Alt キーを押しながら文字入力をテストできます。
- 下部の「リアルタイムログ」で、キーの単体押しやコンボキーがどのように検知されたかを視覚的に確認できます。
- 画面右下の「トレイに最小化」または閉じるボタン（×）を押しても、常駐は継続されます。

### 4. タスクトレイの右クリックメニュー
- **有効 (AltでIME切り替え)**: 一時的に機能をON/OFFできます。
- **IME切り替え方式**:
  - `標準 (VK_IME_ON/OFF)` [推奨]
  - `変換・無変換 (VK_CONVERT/NONCONVERT)`
- **Windowsログオン時に自動起動**: スタートアップ登録の切り替え。
- **切り替え通知を表示**: IME切り替え時にトレイバルーン通知を出すかどうか。
- **設定 / 動作ログを開く...**: 設定画面を表示。
- **終了**: アプリケーションを終了します。

## 📦 スタンドアロンインストーラ

他のPCへ配布したり、ワンクリックでインストール・アンインストールを行いたい場合は、生成されたスタンドアロンインストーラを使用できます。

### インストーラファイル
- **ファイルパス**: [`dist/IMEKeyBinder_Setup_v1.0.0.exe`](file:///c:/Dev/IMEKeyBinder/dist/IMEKeyBinder_Setup_v1.0.0.exe)
- **特徴**:
  - **.NET ランタイム不要**: .NET 10 を内包した自己完結型（SingleFile）のため、.NETが未導入のクリーンなWindows PCでもそのまま動作します。
  - **日本語ウィザード**: 分かりやすいセットアップ画面で、インストール先やスタートアップ自動起動、デスクトップアイコン作成を選択可能。
  - **管理者権限不要**: 一般ユーザー権限でもインストール可能（全ユーザー対象または現在のユーザー対象を選択可能）。
  - **自動プロセス管理**: アップデート時やアンインストール時に実行中の `IMEKeyBinder` を自動検知して安全に終了。
  - **完全なアンインストール**: コントロールパネルの「インストールされているアプリ」からいつでも安全にアンインストール可能。

### インストーラの再ビルド
インストーラを再生成したい場合は、以下のスクリプトを実行するだけで自動的に .NET 発行と Inno Setup パッケージングが行われます：
```powershell
.\build-installer.ps1
```
